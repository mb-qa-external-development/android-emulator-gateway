# Android Emulator Gateway

This is an independent project. It is not affiliated with, endorsed by, or connected to MB Bank.

This gateway hosts the `Pixel_10_Android_17` AVD on this Windows PC. Browser users can view and control it; CI can run Appium UiAutomator2 sessions. One controller holds the device at a time. App data persists between runs.

## Open it

Public URL: **`https://<your-hostname>.<your-tailnet>.ts.net:8443`**

The initial browser password is stored on this PC in the workspace's `work\gateway-data` directory:

```powershell
Get-Content "..\..\work\gateway-data\initial-password.txt"
```

Keep the password private. To replace it, run `npm run cli -- rotate-password` from this directory. Password rotation invalidates browser sessions and the current CI token. `npm run cli -- rotate-ci-token` is an emergency local command that also invalidates the current CI token.

The gateway runs at `127.0.0.1:8765`, Appium at `127.0.0.1:4723`, and Tailscale Funnel publishes only gateway port 8443. The `AndroidEmulatorGateway` scheduled task starts the local processes after Windows sign-in and restarts them if they exit. Windows sleep or shutdown ends access until the PC is awake and signed in again.

## Local source setup

This repository contains the gateway source and pinned npm dependency versions. The Android SDK, AVD data, Appium driver installation, credentials, camera files, and logs are local runtime state and are not committed. On this PC, the startup script expects `work\android-sdk` and `work\gateway-data` two directories above this project. `ANDROID_SDK_ROOT`, `GATEWAY_DATA_DIR`, `APPIUM_HOME`, `JAVA_HOME`, and `GATEWAY_ORIGIN` can be set in the Windows user environment when using another location or Funnel hostname.

`GATEWAY_ORIGIN` sets the gateway origin (default: `http://localhost:8765`). For Funnel access, set it to `https://<your-hostname>.<your-tailnet>.ts.net:8443`.

From the project directory, after installing Node.js, Android Studio, and the `Pixel_10_Android_17` AVD:

```powershell
npm ci
npm run build
$env:APPIUM_HOME = (Join-Path (Split-Path -Parent (Split-Path -Parent (Get-Location))) 'work\gateway-data\appium')
node node_modules\appium\index.js driver install uiautomator2
.\scripts\install-startup.ps1
```

Install or configure Tailscale Funnel separately to forward HTTPS port 8443 to `http://127.0.0.1:8765`. Run `npm run build` before restarting the gateway after source changes. `dist\` and `public\app.js` are generated by the build and excluded from Git.

## Browser controls

Sign in, click **Take control**, then tap, swipe, or type. Only one manual controller or Appium test can hold the device; other signed-in browser windows can view it. Screenshots use the full device resolution. **Enable speaker audio** starts playback after a browser click.

For direct typing, tap a text field on the Android screen and type with your physical keyboard. The phone's on-screen keyboard opens when Android reports a focused text field on supported browsers; tap **Keyboard** in the screen box if it does not. Press **Esc** to release keyboard focus. The **Type** field remains available as a fallback.

**Match ID 1** simulates a fingerprint touch for Android fingerprint ID 1; first enroll that fingerprint in Android Settings. **Reject ID 9999** sends a non-enrolled ID. Uploading a PNG, JPEG, or video for the rear camera restarts the emulator without wiping its data. **Use default camera** removes that source.

## Appium

Point an Appium client at `https://<your-hostname>.<your-tailnet>.ts.net:8443/webdriver` and send the CI token as `Authorization: Bearer <token>` on **every** request. In the browser's **Appium capabilities** tab, enter the browser sign-in password and click **Get today's CI token**. The token changes automatically at midnight in `Asia/Bangkok`; the previous day's token then stops working. A test that crosses midnight must fetch the new token for subsequent commands. The gateway pins `platformName=Android`, `appium:automationName=UiAutomator2`, and `appium:udid=emulator-5554` on session creation. Example W3C request:

The browser's **Appium capabilities** tab shows the required values, gateway defaults, and the complete capability list from the installed UiAutomator2 driver. It lists launchable apps currently installed on the emulator. Choose one to add `appium:appPackage`, `appium:appActivity`, and `appium:forceAppLaunch` to a copyable session request. This selection prepares a request for your test client; it does not change other clients' sessions or erase app data.

```http
POST /webdriver/session
Authorization: Bearer <token>
Content-Type: application/json

{"capabilities":{"alwaysMatch":{"appium:noReset":true,"appium:newCommandTimeout":300},"firstMatch":[{}]}}
```

The gateway does not wipe the device between tests. Delete the WebDriver session when finished. A stalled session loses its lease after about five minutes of inactivity.

## Maintenance

Run `npm install` and `npm run build` in this directory after changing the source. Restart the `AndroidEmulatorGateway` scheduled task to run the new build. Runtime files and logs live under `..\..\work\gateway-data`; the service's SDK copy is under `..\..\work\android-sdk`. Keep both directories alongside the gateway project. Android Studio remains in its standard installed location. The scheduled task runs in your interactive Windows session after sign-in.

Tailscale Funnel must remain enabled for public access. Disable only this public route with `tailscale funnel --https=8443 off`.

## Health checks

After signing back into Windows, check that the scheduled task is running and the Tailscale Funnel route is present:

```powershell
Get-ScheduledTask -TaskName AndroidEmulatorGateway
& 'C:\Program Files\Tailscale\tailscale.exe' serve status
```

The public URL should show the sign-in page. Sign in from another network to confirm the screen and controls. The browser's **Match ID 1** action needs fingerprint ID 1 enrolled on the emulator and an app waiting for a fingerprint. **Reject ID 9999** supplies an unenrolled ID to the same prompt.

If the URL does not resolve off the tailnet, check public DNS with `nslookup <your-hostname>.<your-tailnet>.ts.net 1.1.1.1`. Funnel can report enabled before its public DNS record appears. The local `tailscale funnel status` command confirms the route but does not confirm public DNS.

If the hostname does not resolve off the tailnet, compare the local Funnel status with public DNS. A Funnel route can be enabled before its public DNS record is available.
